# SEO Growth Plan

Last updated: 2026-05-20

Google Search Console snapshot:

- 100 clicks and 356 impressions in the last 28 days.
- Branded queries dominate: `coopverse` and `coopverse.io`.
- Best non-branded opportunity: `.io` searches. `mejores juegos io` / `mejores juegos .io` are already around positions 10-11 with impressions but almost no clicks.
- Coverage shows 73 discovered but not indexed pages. This is a sign to publish fewer, stronger pages rather than many thin game pages at once.
- Some old account/profile URLs appeared in search data. These are now noindexed, so Google should stop showing them after recrawling.

Near-term priorities:

1. Improve pages already close to page one:
   - `/es/blog/juegos-io-multijugador-mejores`
   - `/es/blog/juegos-multijugador-sin-descargar-movil`
   - `/es/g/defly-io`
   - `/es/g/battledudes-io`
   - `/es/g/shell-shockers`
2. Add original comparisons, screenshots/neutral thumbnails, player-count details, controls, and "best for" sections to important game pages.
3. Add games in curated batches of 5-10, then watch indexing before adding more.
4. Keep `/play/*` noindexed. The indexable page should be `/g/[slug]`, where we can add useful text and internal links.
5. Do not index a new language until it has real translated content and a useful blog/category surface. English can be considered later; Hindi should wait until there is native-quality Hindi content and a clear reason from Search Console.

Adding many games quickly is risky because it can create thin pages, duplicate provider descriptions, weak crawl signals, and AdSense quality issues. The better growth loop is: add a focused batch, improve the category/article cluster around it, submit sitemap, wait for Search Console data, then repeat.
